This module allows painless [Sentry](https://sentry.io/) integration
with Odoo: server-side errors and logged errors out of the box, and,
when enabled, APM tracing of requests, SQL and crons, Sentry Metrics
and host/database gauges, Sentry Crons check-ins for `ir.cron`,
queue_job tagging, Sentry Logs, and the browser Loader Script for
frontend errors and Session Replay.
